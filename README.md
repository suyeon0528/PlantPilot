# PlantPilot

PlantPilot은 React와 Vite로 만든 IoT 기반 반려식물 관리 **웹 프로토타입**입니다. 센서 환경 확인부터 급수 추세 예측, 가상 급수, 급수 전후 확인값 및 관리 기록까지 하나의 사용자 흐름으로 체험할 수 있습니다.

> 모든 측정값, 기기 연결, 물탱크 및 펌프 동작은 브라우저에서 생성되는 데모 시뮬레이션입니다. 실제 ESP32, 워터펌프, Spring Boot 서버, AI/머신러닝 API와 연결되어 있지 않으며 식물별 권장 생육값을 나타내지 않습니다.

## 실행 방법

1. Node.js LTS와 npm을 설치합니다.
2. 프로젝트 폴더에서 의존성을 설치합니다.

   ```bash
   npm install
   ```

3. 개발 서버를 실행합니다.

   ```bash
   npm run dev
   ```

4. 터미널에 표시되는 로컬 주소(기본 `http://localhost:5175`)를 브라우저에서 엽니다. 기존 프로젝트와 개발 서버 포트가 겹치지 않도록 5175를 사용합니다.

프로덕션 빌드는 `npm run build`, 빌드 결과 미리보기는 `npm run preview`를 사용합니다.

## 주요 기능

- 초기 식물 3종과 대시보드 상태 요약
- 식물 추가, 수정, 삭제, 기기 선택 및 사용자 관리 기준 설정
- 식물별 환경 모니터링과 24시간/7일/30일 가상 데이터 그래프
- 새 가상 측정값 생성 및 급수 이벤트 그래프 표시
- 3회 이동평균과 선형 추세를 이용한 급수 기준 도달 시점 데모 예측
- 급수 확인 모달, 가상 펌프 애니메이션, 급수량 및 하루 안전 한도
- 급수 후 센서 안정화 확인값, 급수 전후 비교와 히스토리 기록
- 수분 부족, 급수 실패 의심, 센서 이상, 과습 위험 알림 시나리오
- 성장 일지와 사진 등록, 가상 기기 연결/해제
- 주요 데이터와 설정의 브라우저 `localStorage` 저장

## 기술 구성

- React 18, JavaScript/JSX, Vite
- Tailwind CSS 3 및 반응형 CSS
- React Router, lucide-react, Recharts
- `src/data/mockData.js`: 초기 데모 데이터
- `src/context/AppContext.jsx`: 공유 앱 상태 및 브라우저 저장
- `src/services/plantService.js`: 향후 Spring Boot API 어댑터 경계
- `src/utils/analysis.js`: 기준 상태 판정, 추세 예측, 규칙 기반 알림

데모 상태를 원래 값으로 되돌리려면 사이드바의 **데모 데이터 초기화**를 누릅니다. 데이터는 현재 브라우저의 로컬 저장소에만 저장됩니다.
